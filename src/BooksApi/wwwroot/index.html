🔑 API გასაღები

გასაღები თქვენი პროექტის „sandbox“-ია: თქვენი მომხმარებლები, გამოწერები და წიგნები მხოლოდ მასზე ჩანს. ერთი სტუდენტი — ერთი გასაღები.

✅ თქვენი გასაღები — შეინახეთ, მეორედ ვეღარ ნახავთ:

შეინახეთ .env ფაილში: VITE_API_KEY=

სწრაფი დაწყება

შეამოწმეთ გასაღები — ყველა /api მოთხოვნას სჭირდება ჰედერი X-API-KEY. 
curl /api/books?pageSize=3 \
  -H "X-API-KEY: YOUR_API_KEY"
JavaScript-დან — ერთი ფუნქცია, რომელიც ყველა მოთხოვნას ამატებს გასაღებს და ტოკენს: 
const API = '';
const API_KEY = import.meta.env.VITE_API_KEY; // 'YOUR_API_KEY'

export async function api(path, { method = 'GET', body, token } = {}) {
  const res = await fetch(API + path, {
    method,
    headers: {
      'X-API-KEY': API_KEY,
      'Accept-Language': 'ka',
      ...(body ? { 'Content-Type': 'application/json' } : {}),
      ...(token ? { Authorization: `Bearer ${token}` } : {}),
    },
    body: body ? JSON.stringify(body) : undefined,
  });
  const data = res.status === 204 ? null : await res.json();
  if (!res.ok) throw data; // { status, code, detail, errors? }
  return data;
}

const { items } = await api('/api/books?sort=rating');
მომხმარებლის ციკლი — რეგისტრაცია → კოდი ინბოქსიდან → დადასტურება → უფასო საცდელი → კითხვა: 
const { accessToken } = await api('/api/auth/register', { method: 'POST',
  body: { firstName: 'Nino', lastName: 'Beridze', email: 'nino@example.com', password: 'Reading2026' } });

const inbox = await api('/api/sandbox/inbox?email=nino@example.com'); // სატესტო "ფოსტა"
const auth = await api('/api/auth/verify-email', { method: 'POST',
  body: { email: 'nino@example.com', code: inbox.items[0].code } });

await api('/api/subscription/trial', { method: 'POST', body: { planId: 1 }, token: auth.accessToken });
const { url } = await api('/api/books/12/read', { token: auth.accessToken }); // → <iframe src={url}>
